The Gilded Vault is a complete original 2D top-down stealth heist game: sneak across three guarded floors, read patrol cones and sweeping cameras, throw coins and smoke to slip past, crack the vault, grab every piece of loot and reach the exit before the alarm hits 100%.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game is plain static files with all art drawn in code and all sound synthesised with WebAudio.
